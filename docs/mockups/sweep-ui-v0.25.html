F13LD.sweep · UI mockups

Three layouts for v0.25.0. All three move every sidebar setting into F13LD.lab's dock + Configure drawer, drop the seven stat cards for a one-line funnel above the table, and shrink the pipeline log to a chip in the dock (its full text opens in the drawer). Active controls are neon; Sweep's amber stays for the tool name, the header tile and Run. Click Configure, a dock tag or the log chip to open the drawer; click a table row to select it.

1440 × 900, scaled to fit
A — recommended. The design space takes the top two-thirds of the width, the selected design's preview and key numbers sit beside it, and the table runs full width below, so all 8 metric columns fit. Phone: plot, then preview, then table.
B. The plot is a tall square on the left; the table sits beside it on the right with the preview strip under it. The table gets about 650 px, so it shows the rank metrics, VF and stiffness, and the rest move to the detail view. Phone: same as A.
C. The plot fills the screen like a map; the table is a sheet that slides up from the dock (half, full or tucked away) and the preview floats over the plot. Most immersive, but the plot is partly covered while you read the table.
